# Sistema de Inventario

Este proyecto permite **registrar productos** y **consultarlos** de manera sencilla.

---

## Tecnologías utilizadas
- **PHP** 8.2.12  
- **MariaDB** 8.0.30  
- **CSS**  

---

## Requisitos previos
1. Instalar un servidor local:
   - [XAMPP](https://www.apachefriends.org/)  
   - [Laragon](https://laragon.org/)  
   - [HeidiSQL](https://www.heidisql.com/) *(opcional)*  

2. Instalar un editor de código (ej. VS Code, Sublime Text, PhpStorm).

---

## Instalación del proyecto
1. Ubica el proyecto en una de las siguientes rutas:
   - `Win/laragon/www/`
   - `Win/xampp/htdocs/`

2. Descomprime el proyecto en la carpeta seleccionada.  
3. Enciende tu servidor local (XAMPP o Laragon).  
4. Crea la base de datos con el nombre:  



---

## Acceso al sistema
Abre tu navegador preferido (Chrome, Firefox, etc.) y utiliza la siguiente ruta:

- **Laragon** → `http://localhost:80/inventario/index.php`  
- **XAMPP** → `http://localhost/inventario/`

---

## Notas
- Asegúrate de que el servidor de base de datos esté activo antes de acceder.  
- Si usas HeidiSQL, puedes gestionar la base de datos de forma visual.  
- El proyecto está diseñado para funcionar en entornos Windows con XAMPP o Laragon.
